# Интерактивная карточка оценки

Небольшой проект с Frontend Mentor, в котором пользователь может выбрать оценку от 1 до 5 и отправить её.

После нажатия на кнопку Submit появляется вторая карточка с благодарностью и выбранной оценкой.

## Использованные технологии

- HTML
- CSS
- JavaScript
